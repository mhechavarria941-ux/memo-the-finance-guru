# Memo, the Finance Guru (`memo-the-finance-guru`)

**Open Finance & Accounting Studio** — Learn accounting, corporate finance, and market study from the ground up with **Memo**, your friendly, sleepy-wise finances guru owl.

Built with 100% free, open-access educational materials (**OpenStax**, **U.S. SEC EDGAR / Investor.gov**, **Federal Reserve FRED**, and **MIT OpenCourseWare**).

## Features

- **Complete 16-Level Curriculum Ladder (250+ Subtopics)**:
  1. **Level 1 — Business and Financial Math** (Percentages, ratios, markup vs. margin, cash vs. profit, compound interest)
  2. **Level 2 — Accounting Foundations** (Accounting equation, double-entry, debits & credits, accrual vs. cash, CapEx vs. OpEx)
  3. **Level 3 — Journals, Ledgers, and Transaction Recording** (T-accounts, general & subsidiary ledgers, trial balances, adjusting & closing entries)
  4. **Level 4 — Everyday Bookkeeping and the Accounting Close** (Invoicing, bank reconciliations, payroll, prepaids, deferred revenue, depreciation)
  5. **Level 5 — Financial Statements and Their Connections** (Income statement margins, balance sheet, cash flow statement, 3-statement linkages)
  6. **Level 6 — Excel and Financial Data Skills** (Mixed references, Excel Tables, `SUMIFS`, `XLOOKUP`, `INDEX/MATCH`, PivotTables, Power Query)
  7. **Level 7 — Cost Accounting and Operating Performance** (COGS, FIFO/LIFO, ABC, Contribution Margin, Break-Even, Restaurant Prime Cost)
  8. **Level 8 — Financial Analysis, ROI, ROIC & Performance Management** (ROI, ROA, ROE, ROIC, DuPont Analysis, EBITDA, Free Cash Flow, CCC)
  9. **Level 9 — Market Research and Competitive Analysis** (TAM/SAM/SOM, price elasticity, LTV:CAC, SWOT, PESTLE, Porter's Five Forces)
  10. **Level 10 — Budgeting, Forecasting, and Financial Modeling** (Operating/cash budgets, driver-based rolling forecasts, integrated 3-statement models)
  11. **Level 11 — Corporate Finance Fundamentals** (Time value of money, NPV, IRR, Payback, Cost of Debt/Equity, WACC, Capital Structure)
  12. **Level 12 — Financial Markets and Investment Analysis** (Stocks, bonds, ETFs, yield curves, credit spreads, Beta & CAPM, FX, derivatives)
  13. **Level 13 — Valuation and Investment Decisions** (Enterprise Value vs. Equity Value, DCF FCFF/FCFE, Terminal Value, Trading Comps, Multiples)
  14. **Level 14 — Advanced Accounting, Tax, and Controls** (GAAP vs. IFRS, ASC 606, ASC 842 leases, Deferred Taxes, Diluted EPS, Consolidations)
  15. **Level 15 — Advanced Corporate Finance and Transactions** (M&A, Quality of Earnings, Synergies, Accretion/Dilution, PPA, LBO Modeling, Cap Tables)
  16. **Level 16 — Strategic Finance, Risk, and Advanced Market Study** (Capital Allocation, Economic Profit / EVA, Real Options, Monte Carlo, Econometrics)
- **Spaced-Repetition Swipe Flashcards (SuperMemo SM-2)**: Physical swipe gestures and AI-powered custom flashcard generation.
- **Interactive AI Scenario Quizzes**: Concrete dollar-ledger audits with instant diagnostic explanations.
- **Analytics, Daily Learning Minutes Goal & Pedagogical Tasting Styles**: Circular progress ring for daily learning minutes, teacher diagnostic rubrics, and personalized study plan generator.
- **Offline-First PWA & Firebase Cloud Backup**: Installable on iOS, Android, and desktop with Firestore synchronization and a peer support forum.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Copy `.env.example` to `.env` and add your `GEMINI_API_KEY`:
   ```bash
   cp .env.example .env
   ```
3. Start the full-stack development server on port `3000`:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   npm start
   ```
